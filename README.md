# Subscription Analytics Dashboard

モバイルアプリのサブスクリプション契約状況をリアルタイムに可視化するダッシュボードです。

## 使い方

```bash
# ブラウザで直接開く
open index.html

# または任意のHTTPサーバーで配信
npx serve .
python3 -m http.server 8000
```

外部依存は CDN 経由の Chart.js のみ。ビルド不要で `index.html` を開くだけで動作します。

## 機能一覧

### KPI カード

| 指標 | 説明 |
|------|------|
| 有効サブスク数 | 最新日の有効サブスクリプション合計 |
| 新規サブスク | 選択期間内の新規獲得合計 |
| 解約数 | 選択期間内の解約合計 |
| MRR | 最新日の月次経常収益（年額プランは月割り換算） |
| トライアル転換率 | 選択期間内の平均転換率 |

各カードには前半/後半の比較変動率がバッジで表示されます。

### チャート

- **有効サブスクリプション推移** — エリアチャート（全幅）
- **新規 vs 解約** — 上下バーチャート（正: 新規 / 負: 解約）
- **MRR 推移** — エリアチャート
- **トライアル転換率** — ラインチャート
- **プラットフォーム別内訳** — ドーナツチャート（iOS / Android）

### フィルタ

すべてのフィルタはリアクティブに連動し、KPI・チャート・テーブルが即座に再描画されます。

| フィルタ | 選択肢 |
|----------|--------|
| 期間 | 日付ピッカー or クイック選択（7日/30日/90日/180日/1年） |
| プラットフォーム | すべて / iOS / Android |
| プラン | すべて / 月額プラン / 年額プラン |

### 生データビューア

ヘッダーの **「生データ」** ボタンからモーダルを開き、フィルタ適用済みの全レコードを確認できます。

- **テーブル表示**: スクロール可能なテーブル形式
- **JSON 表示**: 整形済み JSON
- **コピー**: クリップボードにコピー（テーブル時は TSV、JSON 時は JSON）
- **CSV エクスポート**: BOM 付き UTF-8 CSV をダウンロード（Excel 対応）

### ダミーデータ仕様

400日分のデータを iOS/Android × 月額/年額の 4 セグメントで生成します。

- **ページ読み込みごとに異なるデータ**: ランダムシードにより毎回異なるパターン
- **ランダム化される要素**:
  - セグメントごとの初期有効数・新規獲得ベース・解約ベース・トライアル転換ベース
  - 全体の成長率と季節変動の強さ
  - キャンペーンスパイク（2〜4回、数日間の連続バースト）
  - 解約イベント（1〜2回、数日間の急増）
  - 週末の落ち込み幅
  - 日次のランダムノイズ
- **現実的なトレンド**: 成長カーブ、週末ディップ、冬季の季節変動を再現
